## How to choose what to do first

- **Fastest visible wins / lowest risk:** 001 and 002 (both S, self-contained,
  ship real user value in a session each).
- **Compounds on what was just shipped:** 003 builds directly on the new pill
  system — high polish-per-effort.
- **Highest value, but a research bet:** 005 is the flagship (the real Wispr
  differentiator) — but it is scoped as a **spike**: it produces evidence + a
  GO/NO-GO, not a shipped feature. Do this when you want to answer "can we do
  AI formatting locally without breaking trust?" with data. If GO, a separate
  productionization plan gets written.
- **Roadmap parity + monetization candidate:** 004 (snippets).

Recommended if doing them in sequence: **001 → 002 → 003** (quick momentum, each
independently shippable), then **005** as the flagship spike, with **004** slotted
whenever snippets are prioritized.

## Findings considered and rejected (so they aren't re-audited)

These came up in the audit or direction pass and were deliberately NOT turned
into plans:

- **Streaming preview for faster-whisper**: deep-dive verdict was HARD / likely a
  trap. The incremental decoder presumes an independent, cheap, concurrent
  decoder — false for the single-subprocess, single-inflight faster-whisper worker.
  Delivering it means a second model in VRAM (OOM risk) or a streaming protocol
  rewrite on both sides, and the preview work steals GPU time from the FINAL
  decode — risking a regression in the app's headline release-to-text latency to
  add speculative text. Deferred; only revisit behind a GPU-only second-instance
  opt-in with an explicit VRAM budget. (Full analysis in project memory.)
- **Activating the monetization/billing layer**: a deliberate, documented business
  hold ("Pro included for everyone", checkout intentionally disabled), not
  stated-but-undelivered scope. The Lemon Squeezy plumbing already lights up when
  that decision flips. Not a feature to build — a timing decision for the maintainer.
- **React 19 / Vite 8 / Tailwind 4 upgrades**: no EOL or security force; Tailwind 4
  is a config rewrite for ~zero benefit. Intentional hold.
